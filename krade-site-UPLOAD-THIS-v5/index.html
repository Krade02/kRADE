THE QUESTION

Which parts of a café visit leave people least satisfied, and did anything change after the café’s new queue system in week 8?

WHERE 73% COMES FROM

264 of the 360 answers rated the visit 4 or 5 out of 5. 264 ÷ 360 = 73.3%. To check it yourself, download the dataset, open it in a spreadsheet and enter =COUNTIF(E2:E361,">=4")/COUNTA(E2:E361). The same arithmetic for the current filter is shown above the chart.

THE DATA

All 360 responses are made up. A script generated them for an imaginary café, and the week-8 change was built in on purpose. This demonstrates a method, not a real business result.

TOOLS, AND WHO BUILT WHAT

HTML, CSS and JavaScript for the page, SVG for the chart, CSV for the data. The page code was written with AI assistants working from my brief, so the code is not evidence of my programming skill.

WHAT THE DATA SHOWED

In this data, lunch satisfaction is 33% (29 of 89 answers) before week 8 and 79% (44 of 56) from week 8 onwards. Because that pattern was built in, it only proves the method works. In real data, a before-and-after comparison alone cannot show what caused a change, and small weekly samples are noisy.

THE SQL I RAN ON THE SAME DATA

Five short queries on the survey table. Each one reproduces a number from the page above, so you can see the same answers come out of code as out of the spreadsheet. I wrote them with AI help and checked every result against the page. Open one to see the code and what it returned.

1. Overall satisfaction: share of answers rated 4 or 5.

Expect 264 of 360 = 73.3%.

SELECT COUNT(*) AS answers,
       SUM(rating >= 4) AS satisfied,
       ROUND(100.0 * SUM(rating >= 4) / COUNT(*), 1) AS pct_satisfied
FROM survey;

2. Net Promoter Score: (promoters 9-10 minus detractors 0-6) divided by answers.

Expect 86 promoters, 126 detractors, NPS -11.

SELECT SUM(recommend_0_10 >= 9) AS promoters,
       SUM(recommend_0_10 <= 6) AS detractors,
       ROUND(100.0 * (SUM(recommend_0_10 >= 9) - SUM(recommend_0_10 <= 6)) / COUNT(*)) AS nps
FROM survey;

4. Satisfaction by time of day, before and after the new queue system (week 8).
SELECT daypart,
       CASE WHEN week < 8 THEN 'before wk 8' ELSE 'from wk 8' END AS period,
       COUNT(*) AS answers,
       ROUND(100.0 * SUM(rating >= 4) / COUNT(*), 1) AS pct_satisfied
FROM survey
GROUP BY daypart, period
ORDER BY daypart, period;
